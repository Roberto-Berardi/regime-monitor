# Earlier work

The first version of this project was a nine-asset equal-risk-contribution
portfolio. Testing it showed that ERC concentrated the book in whichever
asset happened to be calmest — at one point half the portfolio sat in a
single Treasury proxy — and that the construction suited the method rather
than the question.

The code is kept here because the reasoning that replaced it is part of the
project. None of it runs; the live pipeline is `precompute_rotation.py`.
